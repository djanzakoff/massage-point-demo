СТУДИЯ МАССАЖА — версия для GitHub Pages

Название: СТУДИЯ МАССАЖА. Шкала интенсивности: 1–5.
Первый экран: плавное вращение объекта и колец.
Выбор массажа: медленная круговая карусель с надписями, ручное листание.

На iPhone сохраните ZIP в «Файлы», затем коснитесь архива для распаковки.
В корень репозитория нужно загрузить содержимое папки, а не сам ZIP.
Замените index.html, app.js, art.js, carousel.js, style.css и three.module.js.
Сохраните также THREE_LICENSE.txt.
Не удаляйте остальные файлы репозитория без необходимости.

Для нового адреса можно назвать репозиторий massage-studio-demo.
Переименование архива само по себе не меняет адрес сайта.

Это демонстрация без подключения к CRM: номер телефона и пожелания
не отправляются мастеру. Для работы JavaScript-модулей нужен веб-хостинг;
просмотр index.html через приложение «Файлы» не заменяет GitHub Pages.
